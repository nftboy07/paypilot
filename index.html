🔌 How the PayPal integration works

PayPilot is built around the PayPal Orders v2 API (checkout) and the PayPal Invoicing API. Because this hackathon build ships without the entrant's personal sandbox credentials, the live payment step runs as a clearly-labelled sandbox simulation: every simulated step maps 1-to-1 to a real PayPal API call, and the integration points are stubbed in the source (`PAYPAL_CONFIG` + `PayPalAdapter` in this file). Paste a free sandbox client-id from developer.paypal.com into that config block and the same checkout preview calls the real PayPal sandbox — no other changes needed. Full mapping: see README.md.

FLOW Create invoice (AI parse) → PayPalAdapter.createOrder() POST /v2/checkout/orders [STUB → simulation] → Buyer approves in PayPal popup PayPal JS SDK approval [STUB → simulation] → PayPalAdapter.captureOrder() POST /v2/checkout/orders/{id}/capture [STUB] → Invoice status flips to PAID, receipt ID issued (e.g. PAYPILOT-SIM-…)
